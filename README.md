# 🚨 RoadSOS - Emergency Response System

## 📌 Project Description
RoadSOS is a web-based emergency response system designed to improve road safety by allowing users to instantly send SOS alerts during emergencies. The system provides separate dashboards for users and admins.

---

## 🚀 Features

### 👤 User Side
- Login system (Username, Email, Role)
- SOS emergency trigger system
- Category-based emergency selection
- Location detection (demo mode)
- Responsive UI

### 🛠 Admin Side
- Admin dashboard
- Live SOS alerts view
- Recent activity tracking
- Map integration (OpenStreetMap)
- Analytics section (UI)

---

## 🧰 Tech Stack
- HTML
- CSS
- JavaScript

---

## 📂 Project Structure
- landing.html (Login Page)
- user.html (User Dashboard)
- admin.html (Admin Dashboard)
- assets/ (Images)
- CSS & JS files for each module

---

## 🎯 How to Run
1. Open `landing.html`
2. Enter username, email, password
3. Select role (User/Admin)
4. Click Login
5. Explore dashboard features

---

## ⚠ Disclaimer
This project is a **demo prototype built for hackathon purposes only**. It does not connect to real emergency services.
